About

A web app for making SVG maps of any city, state, or country from OpenStreetMap data, for laser engraving, pen plotters, and print. Everything runs in the browser.

Search for a place, then drag the frame on the map to set the area and the size of the piece. Pieces can be rectangles, circles, hexagons, or cut along the outline of a state or country. Layers, colors, titles, names, pins, and GPX routes are set in the sidebar, and the preview shows the SVG as it will be exported.

Each output is set up for its machine. Laser files give every layer its own color, so engraving, scoring, and cutting can each get their own process. Plotter files hatch filled areas, put each pen on its own layer, and order the strokes to cut down pen-up travel. Print files add color themes, place names, and elevation lines.

SVGmap replaces laserSVG, my earlier Blender add-on for laser engraving maps.
