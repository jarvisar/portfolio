Open PartyLine Source Demo video

Joining a queue, the queue itself, and Spotify search.

About

PartyLine is a collaborative song queue for DJs and hosts at parties. Guests join a queue from their phones, search Spotify, and add songs, and the queue updates for everyone in real time.

The front end is an Angular app. The back end is a Flask API with SQLAlchemy and SQLite, and Socket.IO keeps every client in sync. The frontend and backend branches of the repository hold each half.

This project was left in early development.
