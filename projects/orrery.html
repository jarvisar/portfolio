Solar System Viewer

Three.js app | 2023 - 2025

Open Solar System Viewer Source

Earth, with facts about the planet.

About

A model of the solar system built with Three.js. Click a planet to focus on it, change the date to see where everything was, or switch to the flight mode and fly around the system.

Other star systems can be searched and visited using data from the NASA Exoplanet Archive. Supports game controllers and VR.

This was originally built in 2023 to learn Three.js and WebGL, and has been rebuilt since.
