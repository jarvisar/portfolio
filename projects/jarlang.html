About

JarLang is a small programming language with a lexer, parser, and semantic analyzer that build abstract syntax trees from source code. The interpreter walks the tree to run the program, and a code generator also produces and runs x86-64 assembly.

It has variables, arithmetic, functions, if statements, loops, logical and comparison operators, string formatting, and error handling. The JarLang Playground runs it in the browser and shows the output, AST, tokens, and generated assembly side by side.

The first version was written in 2023 and has been extended since.
