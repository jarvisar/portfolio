About

A simple model of our Solar System built with Three.js. Includes a flight simulator that allows users to fly around the solar system. Users can also click on planets to switch the focus and move the camera, or change the date to see where everything was. You can also search for and visit other star systems using data from the NASA Exoplanet Archive. Supports game controllers and VR. This project was originally built to gain experience with Three.js and WebGL.

Check out the GitHub repo to learn more.
