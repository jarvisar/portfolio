About

A simple model of our Solar System built with Three.js. Includes a flight simulator that allows users to fly around the solar system. Users can also click on planets to switch the focus and move the camera. This project was primarily built to gain experience with Three.js and WebGL.

Check out the GitHub repo to learn more.
